# ממיר מטבעות

אפליקציית אנדרואיד בעברית להמרת סכום למספר מטבעות במקביל, עם שערי מטבע חיים.

מזינים סכום, בוחרים מטבע מקור, מסמנים כמה מטבעות יעד — ורואים כמה זה בכל אחד מהם.

## תכונות

- ממשק עברית ו־RTL
- בחירת כמה מטבעות יעד בבת אחת
- שערי מטבע חיים מ־[exchangerate.dev](https://exchangerate.dev/) (שקל, דולר, אירו, לירה ועוד)
- רענון בכניסה לאפליקציה, ואז כל דקה רק כל עוד המסך פתוח
- שמירת הסכום והמטבעות שנבחרו במכשיר
- מצב בהיר וכהה לפי המערכת

## התקנה

אין צורך ב־Google Play. בכל דחיפה ל־`main` נבנה APK ב־GitHub Actions.

1. נכנסים ל־[Actions](https://github.com/shlomi10/currency-convertor/actions)
2. פותחים את הריצה האחרונה שהסתיימה בהצלחה
3. מורידים את הקובץ `currency-converter` (`app-debug.apk`)
4. מעבירים לטלפון ומתקינים (לאשר התקנה ממקור לא מוכר)

במכשיר האפליקציה מופיעה בשם **ממיר מטבעות**.

## פיתוח

פרויקט Kotlin עם Jetpack Compose. דרישות מקומיות: Android Studio, JDK 17, Android SDK 35.

```bash
./gradlew assembleDebug
```

ה־APK יוצא אל:

`app/build/outputs/apk/debug/app-debug.apk`

## שערים

הנתונים מגיעים מ־[exchangerate.dev](https://exchangerate.dev/). מטבעות מרכזיים מתעדכנים תוך־יום; חלק מהמטבעות הפחות נזילים עשויים להישען על שער ייחוס יומי. השערים לידיעה בלבד, לא לסליקה.
